# Shopping Counter Billing System

A Python command-line project demonstrating shopping cart management and billing logic.

## Project scope

- Manage items in a shopping cart
- Calculate bills, taxes and discounts
- Generate a receipt

## Focus

Python programming fundamentals, conditional logic, user input, and command-line application design.

This is a software fundamentals project rather than a deployed commercial product.
